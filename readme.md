# 📊 학과별 대학 생활습관 및 만족도 분석 대시보드

Streamlit을 이용해 대학생들의 생활 습관(공부시간, 수면시간, 스마트폰 사용시간)과 학교생활 만족도 간의 관계를 분석하고 시각화하는 웹 애플리케이션입니다.

---

## ✨ 주요 기능

1. **CSV 파일 업로드 & 미리보기**: 사용자 데이터를 직접 업로드하고 미리 확인할 수 있습니다.
2. **자동 전처리 및 예외 처리**: 누락된 데이터나 잘못된 형식의 만족도 값을 자동으로 정제하고, 제외된 데이터 건수를 리포트합니다.
3. **학과별 필터링**: 전체 학과 통합 보기 또는 특정 학과 선택에 따른 동적 분석 결과를 제공합니다.
4. **시각화 그래프**:
   - **막대그래프**: 학과별/전체 주요 생활습관 평균 시간 비교
   - **산점도(Scatter Plot)**: 선택한 생활습관 요인과 학교생활 만족도 간의 상관관계 분석
   - **워드클라우드**: 학생들이 작성한 한 줄 의견의 주요 키워드 시각화
5. **텍스트 심층 분석**:
   - 한 줄 의견에서 자주 등장하는 상위 10개 단어 막대그래프 표시
   - 긍정/부정 성향 키워드 기반 감성 분석 및 등장 횟수 비교

---

## 🚀 설치 및 실행 방법

### 1. 사전 요구사항
Python 3.8 이상이 설치되어 있어야 합니다.

### 2. 패키지 설치
프로젝트 루트 디렉토리에서 터미널을 열고 아래 명령어를 입력하여 필요한 라이브러리를 설치합니다.

```bash
pip install -r requirements.txt
```

### 3. 앱 실행
아래 명령어를 실행하여 Streamlit 로컬 웹서버를 구동합니다.

```bash
streamlit run app.py
```

## 📁 CSV 파일 형식 안내
업로드하는 CSV 파일에는 다음과 같은 컬럼이 포함되어야 원활한 분석이 가능합니다:
* `학과`: 학생의 소속 학과 (예: 컴퓨터공학과, 경영학과 등)
* `공부시간`: 하루 평균 공부 시간 (숫자)
* `수면시간`: 하루 평균 수면 시간 (숫자)
* `스마트폰`: 하루 평균 스마트폰 사용 시간 (숫자)
* `만족도`: 학교생활 만족도 점수 (1 ~ 10점 사이의 숫자)
* `한줄의견`: 학교생활에 대한 자유로운 텍스트 의견
